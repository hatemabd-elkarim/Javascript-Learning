# JavaScript Course — Learning Notes

This repo documents my progress learning JavaScript, following the [SuperSimpleDev JavaScript course](https://github.com/SuperSimpleDev/javascript-course). Each **milestone** groups a few lessons together and is written up as a single markdown file (`Milestone-N.md`) with simple explanations, code snippets, and small exercises.

Pace is roughly:

- **Intermediate learners:** ~1–2 days per milestone
- **Beginners:** ~3–4 days per milestone

(Actual time depends on how much you practice the exercises at the end of each lesson — go at whatever pace makes the concepts stick.)

## How this repo is organized

- Each milestone file is self-contained — you don't need to read previous ones to follow the code snippets.
- Every lesson section inside a milestone ends with **Key takeaways** and a **Try it yourself** section for practice.
- Source video: [SuperSimpleDev JavaScript Course](https://www.youtube.com/watch?v=EerdGm-ehJQ)
- Source code walkthrough: [javascript-course repo](https://github.com/SuperSimpleDev/javascript-course)
